# 2.0 首个构建与验证

日期：2026-10-29。目标：macOS Apple Silicon、AE 8 / 16 bpc；Windows 共享核心。

后续已完成 AE 26 实机的 8 / 16 bpc、全 / 半分辨率与多帧验证，见 [V2_AE_VALIDATION.md](V2_AE_VALIDATION.md)。本文保留首次构建当时的模拟测试与阻塞记录。

## 本次实际完成

- 每帧素材只读取转换一次，以非零 RGBA 区域裁剪存储，保留来源坐标与图形视觉尺寸。
- 根据实际素材范围与旋转建立稳定分块索引，完全移除每个 64 行缓冲重新扫描整帧图形的工作。
- 按上层至下层计算像素贡献，仅在剩余透射率为零时结束；不使用近似不透明阈值，不截断每块候选列表。
- Metal 实际执行绘制，内核运行时编译。静态初始化后的计算管线只读共享，各帧独立缓冲。
- GPU 直接量化并生成原生 ARGB8 / ARGB16 输出，保留 AE 行填充；CPU 回退采用相同索引与合成语义。
- Mac 插件构建、签名与格式检查；CMake 共享核心和 CPU 回退入口。

当前是混合加速：从 AE 的 CPU 效果入口获得素材，准备裁剪与索引，交给独立 Metal 队列计算，再复制原生像素到 AE。没有声明 SmartFX GPU 支持，没有假定拿到了 AE 的 GPU 原生资源。此路径能直接服务 8 / 16 bpc，但仍存在输入转换和复制成本。

## 核心与插件入口验证

- 现有布局核心测试通过。
- 新核心覆盖 48 组组合：四类形状、三种旋转、不透明 / 半透明、全 / 半分辨率，CPU 与 Metal 对比通过。
- 小场景 CPU / 参考最大浮点误差约 `2.27e-6`，Metal / 新 CPU 最大误差约 `5.96e-8`。
- 700 项半透明列表验证完整尾部合成；单像素宽 / 高素材、非等比预览、分段输出、行填充、取消和四路并发通过。
- 直接加载实际 `.plugin` 的 `EffectMain`，使用模拟 SDK 回调验证 8 / 16 bpc、全 / 半分辨率、像素行填充、checkout / checkin 清理、取消和四路并发。与参考输出量化后的各通道差不超过 1 个整数级别。
- 临时诊断构建中，最近一次插件入口测试共 14 次调用，其中 13 次记录到 Metal 实际执行，1 次主动取消；最多四次渲染调用同时在执行。这是模拟宿主并发，不是 AE 多帧调度证明。
- Mac 上 CMake 的 CPU / Metal 两种配置均构建并通过测试。Windows 尚无真实编译或运行结果。

## 模拟性能基准

参数按此前场景：1920×1080、图形大小 330、间距 92 / 2、行距 40、渐变强度 79%。使用 1920×1080 的透明背景白色菱形素材及合成径向渐变；不是当前 AE 工程星形素材的实际渲染。

Metal 总时间包含每次素材准备、布局、索引、缓冲创建 / 上传、GPU 绘制和结果复制。每项取五次调用中位数，运行前已触发一次 Metal 初始化。参考与 CPU 回退各计时一次。参考路径使用浮点来源，不能与上次原生整数回调基准混为同一组实验。

| 输出与单图形不透明度 | 参考 CPU | 新 CPU（含准备） | Metal 总时间 | Metal 内核时间 |
|---|---:|---:|---:|---:|
| 960×540，100% | 2768 ms | 92.8 ms | 11.9 ms | 2.24 ms |
| 960×540，35% | 2744 ms | 259 ms | 17.7 ms | 8.19 ms |
| 1920×1080，100% | 10990 ms | 295 ms | 22.2 ms | 10.1 ms |
| 1920×1080，35% | 10983 ms | 916 ms | 39.0 ms | 27.6 ms |

这组样例包含大量透明留白，且不透明图形能跳过后方贡献，属于对新算法有利的场景。约 155–495 倍的样例倍率不能外推为真实 AE、所有素材或 Windows 的收益。16 bpc 最终整数误差、时间稳定性仍应通过实机工程验收。

本次进程首次 Metal 调用约 32.4 ms，可能利用系统已有着色器缓存，不能作为所有机器冷启动时间的保证。

原始数据：`build/raster-benchmark.jsonl`。基准通过 `python3 scripts/build.py --benchmark` 复现。参考代码仍保留作为测试与分析基线，不承担旧版工程兼容。

## 内存与取消边界

Metal 直接生成原生位深结果：4K 单帧 GPU 输出缓冲约 31.64 MiB（8 bpc）或 63.28 MiB（16 bpc），不计 AE 自身输出。来源转换暂时保留整张浮点素材，随后储存裁剪图；另有每帧索引与上传副本。尚未实现跨帧素材缓存和统一 GPU 内存预算。

索引设置每帧 128 MiB 的条目预算，超过预算报错，不静默丢图形。布局仍沿用已有 250,000 候选位置限制。

CPU 阶段与复制阶段定期响应取消，GPU 提交前后响应取消；已提交的一次 GPU dispatch 会等待完成，尚未实现分批提交或执行中取消。这需要通过高覆盖、强半透明的长尾场景继续验证。
